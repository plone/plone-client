# Comments, aliases, relations, and translations

Everything attached to an item that is not one of its fields: comments, old URLs, relations to other items, and translations.
The comments examples install `plone.app.discussion`, and the translations examples install `plone.app.multilingual`, which is what your site needs too.

Each example uses the `client` from {ref}`reference-services-reading`.
